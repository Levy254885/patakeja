Patakeja front page - deployment
1. Upload EVERYTHING in this folder (including the hidden .htaccess) to public_html for www.patakeja.co.ke.
2. Turn on SSL (AutoSSL / Let's Encrypt). .htaccess forces https and www.
3. The sign-up form posts to contact.php, which emails nziokasila8@gmail.com (needs PHP mail(), standard on cPanel).
4. This is the public front page only. Accounts, listings, M-Pesa payments and search are not built yet.
5. Submit /sitemap.xml to Google Search Console.
